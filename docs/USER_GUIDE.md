# 用户使用手册

本手册介绍错题本生成系统的操作流程和常见问题。

---

## 系统简介

错题本生成系统是一个基于 AI 的文档处理工具，支持上传 PDF 或图片格式的试卷，通过 OCR 解析和 AI 智能分割题目，导出为 Markdown 格式的错题本。

**支持的题型**: 选择题、填空题、解答题、判断题

---

| 项目 | 要求 |
|------|------|
| Python | 3.11 |
| 操作系统 | Windows / macOS / Linux |
| 浏览器 | Chrome、Firefox、Edge 等现代浏览器 |

安装和配置步骤请参考项目 [README.md](../README.md)。

## 使用流程

在项目根目录执行 `python web_app.py` 启动系统，然后浏览器访问 **http://localhost:5001**。

页面顶部会显示 PaddleOCR、DeepSeek 等服务的配置状态，如显示未配置请检查 `.env` 文件。

### 步骤 1: 上传文件

将 PDF 或图片文件拖拽到上传区域，或点击选择文件。

- 支持格式: `.pdf`, `.png`, `.jpg`, `.jpeg`, `.bmp`, `.tiff`, `.webp`
- 文件大小限制: 50MB
- 多页试卷建议使用 PDF 格式上传

### 步骤 2: OCR 解析

上传后系统自动进行 OCR 解析，无需操作，等待完成即可。

### 步骤 3: AI 分割题目

点击 **"开始分割题目"** 按钮，系统会自动识别题号、判断题型、提取内容。完成后页面展示所有题目卡片。

### 步骤 4: 预览与导出

勾选需要的题目（可全选），点击 **"导出错题本"** 按钮，下载 Markdown 文件。

---

## 输出文件

| 文件 | 说明 |
|------|------|
| `results/wrongbook.md` | Markdown 格式的错题本，包含题目内容和答案填写区域 |
| `results/questions.json` | JSON 格式的题目结构化数据 |
| `results/split_issues.jsonl` | AI 处理过程中的问题日志 |

## 常见问题

**上传后长时间无响应** — 检查网络连接和 `.env` 中的 API 配置，查看终端日志是否有错误。

**AI 分割结果不准确** — 确保文件清晰度足够（建议 300 DPI 以上），检查 `output/struct/` 下的 OCR 结果。

**公式显示异常** — 使用支持 LaTeX 的 Markdown 编辑器查看（如 Typora、VS Code + Markdown Preview Enhanced）。

**只处理部分页面** — PDF 可先提取需要的页面再上传；或在步骤 4 中只勾选需要的题目导出。
