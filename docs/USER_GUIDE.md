# 用户使用手册

本手册帮助你快速上手错题本生成系统，完成从上传试卷到导出错题本的完整操作。

---

## 系统简介

错题本生成系统可以将 PDF 或图片格式的试卷自动识别、分割为单道题目，并导出为 Markdown 格式的错题本，方便你整理错题和复习。

**支持的题型**: 选择题、填空题、解答题、判断题

**支持的内容**: 纯文字、数学公式（行内/行间）、图片

---

## 环境准备

### 系统要求

| 项目 | 要求 |
|------|------|
| Python | 3.11 |
| 操作系统 | Windows / macOS / Linux |
| 浏览器 | Chrome、Firefox、Edge 等现代浏览器 |

### 安装 poppler

系统需要 poppler 来处理 PDF 文件。根据你的操作系统选择对应方式安装：

- **Windows**: 下载 [poppler for Windows](https://github.com/ossamamehmood/Poppler-Windows/releases)，解压后将 `bin` 目录添加到系统环境变量 PATH
- **macOS**: 终端执行 `brew install poppler`
- **Linux**: 终端执行 `sudo apt-get install poppler-utils`

### 安装与配置

```bash
# 1. 安装 Python 依赖
pip install -r requirements.txt

# 2. 复制环境变量模板并填写 API 密钥
cp .env.example .env
```

打开 `.env` 文件，填写以下必需项（参考文件中的注释说明）：

- `DEEPSEEK_API_KEY` — DeepSeek API 密钥
- `DEEPSEEK_BASE_URL` — DeepSeek API 地址
- `PADDLEOCR_API_URL` — PaddleOCR 服务地址
- `PADDLEOCR_API_TOKEN` — PaddleOCR API 密钥

## 启动系统

在项目根目录执行：

```bash
python web_app.py
```

看到以下输出说明启动成功：

```
============================================================
错题本生成系统 - Web应用
============================================================
访问地址: http://localhost:5001
============================================================
```

打开浏览器访问 **http://localhost:5001** 进入系统主页。

页面顶部的 **系统状态** 栏会显示各项服务的配置情况：

- `✓ PaddleOCR` — OCR 服务已配置
- `✓ DeepSeek` — AI 模型已配置
- `✓ LangSmith追踪` — 调试追踪已启用（可选，不影响使用）

如果 PaddleOCR 或 DeepSeek 显示为 `✗ 未配置`，请检查 `.env` 文件中对应的 API 密钥是否填写正确。

## 使用流程

页面顶部有 4 个步骤指示器（上传文件 → OCR解析 → 分割题目 → 预览导出），当前步骤会高亮显示。

### 步骤 1: 上传文件

页面中央有一个上传区域，你可以：

- **拖拽上传**: 将文件直接拖到上传区域
- **点击上传**: 点击上传区域，在弹出的对话框中选择文件

| 支持的格式 | 扩展名 |
|-----------|--------|
| PDF 文档 | `.pdf` |
| 图片 | `.png`, `.jpg`, `.jpeg`, `.bmp`, `.tiff`, `.webp` |

文件大小限制为 **50MB**。

**建议**：
- 多页试卷优先使用 PDF 格式，系统会自动按页拆分
- 图片尽量清晰，扫描件建议 300 DPI 以上
- 拍照的试卷注意光线均匀、避免倾斜

### 步骤 2: OCR 解析

上传文件后，系统会自动进行 OCR 解析，页面显示加载动画和提示 "正在上传和处理文件..."。

处理完成后，页面会显示文件信息：
- **文件名**: 上传的文件名
- **图片数量**: PDF 拆分出的页数（图片则为 1）
- **OCR结果**: 解析结果数量

此步骤自动完成，无需操作。

### 步骤 3: AI 分割题目

OCR 完成后，点击页面上的 **"开始分割题目"** 按钮。

系统会调用 AI 分析 OCR 结果，自动识别出每道题目的边界、题型和内容。处理过程中页面显示 "正在调用AI分割题目，请稍候..."。

完成后页面显示成功提示（如 "成功分割 10 道题目"），下方展示所有识别到的题目卡片。

每张题目卡片包含：
- **题号**（如 "题目 1"）和 **题型标签**（选择题/填空题等）
- **题目内容**: 文字、数学公式（自动渲染）、图片
- **选项列表**: 仅选择题会显示 A/B/C/D 选项
- **复选框**: 用于勾选该题目

### 步骤 4: 预览与导出

1. **浏览题目**: 查看分割出的所有题目，确认内容是否正确
2. **选择题目**: 点击题目卡片或勾选复选框来选中题目
   - 点击 **"全选"** 可一次选中所有题目
   - 点击 **"取消全选"** 清除所有选择
   - 页面会实时显示 "已选择 X 道题目"
3. **导出**: 点击 **"导出错题本"** 按钮（至少选中 1 道题目）
4. **下载**: 导出成功后页面会出现 **"点击下载"** 链接，点击即可下载 Markdown 文件

如需重新处理，点击 **"重新开始"** 按钮回到初始状态。

## 导出的错题本怎么用

导出的 `wrongbook.md` 是 Markdown 格式文件，每道题目下有三个待填写区域：

- **我的答案** — 记录你的作答
- **正确答案** — 记录标准答案
- **解析** — 记录解题思路和涉及的知识点

你可以用以下工具打开和编辑：
- **Typora**（推荐）— 所见即所得的 Markdown 编辑器，支持公式渲染
- **VS Code** + Markdown Preview Enhanced 插件
- 任何支持 Markdown 的文本编辑器

> 如果公式显示为 `$...$` 原始文本而非数学符号，说明你的编辑器不支持 LaTeX 渲染，请换用上述推荐工具。

## 常见问题

### 上传文件后长时间没有响应

- 检查网络连接是否正常
- 确认 `.env` 中的 `PADDLEOCR_API_URL` 和 `PADDLEOCR_API_TOKEN` 填写正确
- 查看启动系统的终端窗口是否有报错信息
- 尝试上传一张较小的图片测试

### AI 分割结果不准确

- 确保上传的文件足够清晰（建议 300 DPI 以上的扫描件）
- 手机拍照的试卷识别效果不如扫描件，尽量保证光线充足、画面平整
- 部分手写内容或复杂排版可能识别不佳，属于正常情况

### 导出的错题本中图片无法显示

- 确保 `output/` 目录下的图片文件没有被删除
- 用编辑器打开 `wrongbook.md` 时，保持文件在项目目录内，图片使用的是相对路径

### 只想处理试卷中的部分题目

- 系统会识别出所有题目，你可以在步骤 4 中只勾选需要的题目导出
- 如果只想处理某几页 PDF，可先用 PDF 工具（如 Adobe Acrobat、Smallpdf）提取页面后再上传
