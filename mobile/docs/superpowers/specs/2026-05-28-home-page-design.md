# Flutter 首页设计规范

日期：2026-05-28
项目：error_log_app

## 目标

为当前 Flutter 项目搭建第一版可用页面结构。应用需要一个不受登录状态影响的公共首页，使用 `assets/logo.svg` 里的现有 logo，整体采用深色星空动效风格，颜色集中放在 `app_theme`，同时建立后续页面可继续扩展的清晰目录分层。

## 当前项目情况

当前项目是一个基础 Flutter 应用。`lib/main.dart` 同时承担应用启动和空首页组件职责。`assets/logo.svg` 已存在，但 `pubspec.yaml` 还没有声明 assets。当前本机工具链是 Flutter 3.24.5 / Dart 3.5.4，因此 SDK 约束和现有依赖需要兼容 Dart 3.5；BLE 相关依赖需固定在 5.4.1 系列以避免旧 Flutter 不认识的新 pubspec 字段。当前目录不是 git 仓库，因此本工作区无法提交设计文档 commit。

## 选定方案

采用轻量分层结构：

- `main.dart` 只负责启动应用。
- `app/app.dart` 负责 `MaterialApp`。
- `app/router/app_router.dart` 负责路由名称和路由生成。
- `app/theme/app_theme.dart` 负责颜色常量和 `ThemeData`。
- `core/constants` 负责共享资源常量。
- `core/widgets` 负责可复用视觉组件，例如星空背景和按钮。
- `features/home` 负责首页页面组合和首页专用组件。
- `features/workspace` 负责工作台占位页。

这个结构能让项目保持清晰，同时避免在当前阶段提前引入状态管理或过重架构。

## 首页行为

首页无论用户是否登录都直接展示。本次不检查登录状态。

右上角 `进入工作台` 按钮直接跳转到工作台占位页。这样先建立导航路径，后续再补登录拦截。

`开始使用` 按钮也直接跳转到工作台占位页。首页不展示 `查看演示` 按钮。

## 视觉设计

页面参考用户提供的截图：

- 全屏深色背景。
- 低饱和紫色和靛蓝渐变。
- 使用 Flutter Widget 和动画实现闪烁星空，不依赖背景图片。
- 使用自定义绘制实现柔和光晕和淡曲线纹理。
- 顶部栏左侧展示 logo 和应用名 `智卷错题本`。
- 中央 hero 内容包含：
  - `AI 驱动 · 专为学生设计`
  - `重塑错题整理`
  - `一键生成知识图谱`
  - `上传试卷或手写笔记，AI 自动完成 OCR 识别、题目分割、公式还原、知识点标注。`
- 提供 `开始使用` 主按钮。

页面需要适配常见桌面、Web 和移动宽度，文本不能溢出父容器。

## 主题

颜色集中放在 `lib/app/theme/app_theme.dart` 的 `AppTheme` 或应用颜色常量中。

主色板包括：

- 接近黑色的页面背景。
- 深紫色表面和装饰色。
- 淡紫色主按钮。
- 白色主文本。
- 灰色次级文本。
- 低透明度描边和光晕颜色。

继续启用 Material 3。

## 资源

`assets/logo.svg` 是应用 logo 的唯一来源。`pubspec.yaml` 需要声明 `assets/` 目录，保证 Flutter 可以加载 logo。

Flutter 核心 SDK 不直接渲染 SVG 资源，因此实现时会添加 `flutter_svg`，除非项目已有其他 SVG 渲染方案。

## 异常处理

如果 SVG 资源加载失败，logo 区域仍需保持稳定尺寸，不能破坏布局。实现中可以提供一个小图标作为回退。

如果遇到未知路由，路由层应回退到首页或展示一个简单错误页面，不能直接崩溃。
