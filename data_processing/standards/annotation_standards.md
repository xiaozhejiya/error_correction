# 数据标注规范制定

## 概述
本规范定义了试卷数据的标注方式，分为**检测标注 (Detection)**和**识别标注 (Recognition)**两部分。

---

## 1. 标注工具

- **推荐工具**：**PPOCRLable**
  - GitHub：https://github.com/PaddlePaddle/PaddleOCR/tree/release/2.0/tools/PPOCRLabel
  - 支持检测框标注和识别文本标注
  - 可导出 JSON、TXT 等多种格式
  - 集成了 PaddleOCR 模型，可快速预标注

---

## 2. 检测标注 (Detection)

### 2.1 格式规范

采用 **JSON 格式**，记录每个文本区域的四个顶点坐标：

```json
{
  "img_01.jpg": [
    {
      "transcription": "第1题：1+1=",
      "points": [[10, 10], [100, 10], [100, 30], [10, 30]]
    },
    {
      "transcription": "2",
      "points": [[110, 10], [130, 10], [130, 30], [110, 30]]
    }
  ],
  "img_02.jpg": [
    ...
  ]
}
```

### 2.2 坐标说明

- **points**：四个顶点坐标，按顺时针方向标注
  - 格式：`[[x1, y1], [x2, y2], [x3, y3], [x4, y4]]`
  - 左上 → 右上 → 右下 → 左下（标准四边形）
  
- **transcription**：文本框内的完整文本内容

### 2.3 标注原则

| 原则 | 说明 |
|------|-----|
| **包含所有文本** | 试卷上的每一个文本区域都要标注，包括题号、选项、答案等 |
| **紧凑标注** | 标注框大小应紧贴文字，避免过大或过小 |
| **不跨页** | 每个标注框只能标注单个页面内的文本，跨页内容分开标注 |
| **避免重叠** | 不同文本框不能重叠，如有并列选项需分别标注 |
| **特殊情况** | 表格内部的文本需逐个标注，而不是整体标注表格 |

## 3. 识别标注 (Recognition)

### 3.1 格式规范

采用 **TXT 格式**，每行一个条目，格式为 `文件名\t文本内容`：

```
img_01.txt	第1题：1+1=2
img_01.txt	A. 1
img_01.txt	B. 2
img_01.txt	C. 3
img_02.txt	选择下列正确的计算...
```

### 3.2 创建方法

**方式 1：由检测标注导出**
- 使用 PPOCRLabel 的导出功能，从检测框自动提取文本

**方式 2：手工标注**
- 直接建立 `gt_label.txt` 文件，逐行录入
- 保证与检测标注的 `transcription` 字段保持一致

### 3.3 标注原则

#### 3.3.1 横排文本

- **优先整行标注**
- 不需要按字拆分，除非有特定需求（如单字符识别模型）
  
  ```
  # 推荐
  ground_truth: "第1题：求下列方程的解"
  
  # 不推荐（不必要的拆分）
  ground_truth: "第" "1" "题" ...
  ```

#### 3.3.2 特殊符号处理

| 符号类型 | 统一标注方案 |
|----------|-----------|
| **数学公式** | 保留原文本，不转 LaTeX；如需，统一用 `[FORMULA]` 占位 |
| **分数线** | 用 `/` 表示（如 `1/2` 表示二分之一）或 `[FRAC]` 占位 |
| **上下标** | `^` 表示上标，`_` 表示下标（如 `x^2`, `H_2O`）或改用 `[SUP]`、`[SUB]` 占位 |
| **根号** | 使用 `sqrt()` 或 `[SQRT]` 占位（如 `sqrt(2)` 或 `[SQRT]2[/SQRT]`） |
| **空白符** | 保留空格，不用特殊符号替代；若是完全空白行，用 `[BLANK]` 标注 |
| **破损字符** | 用 `[UNK]` 表示无法识别的字符 |

#### 3.3.3 不同题型的标注示例

**选择题**
```
1. 下列哪个选项正确？
A. 选项 A
B. 选项 B
C. 选项 C
D. 选项 D
```

**填空题**
```
2. 计算 1+1=___
```

**解答题**
```
3. 求解方程：
2x+3=7
解：2x=4
x=2
```

## 4. 字体与背景适配

### 4.1 印刷文本

- 标注清晰的印刷体，遵循标准规范
- 若有多种字体（宋体、黑体等），尽量保持一致的标注方式

### 4.2 手写文本

- 如果笔迹清晰，直接标注手写内容
- 如果笔迹模糊或连笔，标注为最可能的字符，并用 `[UNCLEAR]` 标注处可加注釈
- 避免猜测不清楚的内容

### 4.3 特殊背景

| 背景类型 | 处理方式 |
|----------|---------|
| 白纸印刷 | 正常标注 |
| 草稿纸 | 避免混入其他笔迹，若有需要分离标注 |
| 有水印 | 只标注主要文本，忽略水印 |
| 有印章/批注 | 如不影响主要内容，可忽略；否则在旁注 |

---

## 5. 质量检查清单

标注完成后，逐一检查：

- 所有文本框都有对应的 `transcription`
- 坐标格式正确（4 个顶点，格式 `[[x, y], ...]`）
- 坐标精确，框体紧贴文字
- 没有文本框重叠
- 识别标注与检测标注内容一致
- 特殊符号遵循统一规范
- TXT 文件编码为 UTF-8
- 文件名一致（如 `img_01.jpg` 对应的标注引用名相同）

---

## 6. 标注工作流程

```
1. 使用扫描规范 → 获得高质量扫描件
             ↓
2. 打开 PPOCRLabel → 导入扫描件
             ↓
3. 启用预标注模式 → 快速检查纠正
             ↓
4. 手工调整标注框 → 确保精确
             ↓
5. 补充识别文本 → 检查特殊符号
             ↓
6. 导出 JSON + TXT → 保存标注结果
             ↓
7. 质量检查 → 进入benchmark
```

---

## 7. 估算工作量

| 任务 | 估算时间 |
|-----|---------|
| 单张图预标注+纠正 | 5-15 分钟 |
| 50 张试卷完整标注 | 4-10 小时 |
| 100 张试卷完整标注 | 8-20 小时 |
